# Contributor Covenant Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

If you observe behavior that violates this code of conduct, report it to:

**conduct@hybridyn.com**

All reports are reviewed and investigated promptly and fairly. Reporters
will be kept confidential to the extent possible.

## Scope

This Code of Conduct applies within all project spaces — GitHub Issues,
PRs, Discussions, official chat channels, conferences, and any space where
an individual is representing the F-Pulse project.

## Enforcement

Project maintainers will follow the Contributor Covenant Enforcement
Guidelines (https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
when responding to violations.
